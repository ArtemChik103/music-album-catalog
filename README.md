# Music Album Catalog (VinylLog)

Веб-приложение для каталогизации музыкальных альбомов, исполнителей и композиций.
Проект разработан по методологии Specification-Driven Development (SDD).
Исходная спецификация требований и API-контракт зафиксированы в файле [SPECIFICATION.md](SPECIFICATION.md).

---

## Архитектура и структура данных

Приложение моделирует четыре сущности:

1. **Исполнитель (`Artist`)**: имя исполнителя или группы (уникальное значение).
2. **Альбом (`Album`)**: название, ссылка на исполнителя, год выпуска.
3. **Песня (`Song`)**: название музыкальной композиции.
4. **Трек альбома (`AlbumSong`)**: связь многие-ко-многим между альбомом и песней с полем `track_number`.

### Реализация бизнес-правила

Одна песня может входить в разные альбомы с разными порядковыми номерами.
Таблица `AlbumSong` хранит пару внешних ключей (`album_id`, `song_id`) и номер позиции `track_number`.
Ограничение `UNIQUE (album_id, track_number)` исключает дублирование номеров треков в одном альбоме.
Ограничение `UNIQUE (album_id, song_id)` предотвращает повторное включение песни в один альбом.

## Стек технологий

- **Бэкенд**: Python 3.11, Django 5.1, Django REST Framework, django-filter, drf-spectacular, SQLite.
- **Фронтенд**: Vue 3 (Composition API), Vite, Pinia, Tailwind CSS v4, Phosphor Icons.
- **Инфраструктура**: Docker, Docker Compose, Nginx, GitHub Actions CI.

## Запуск через Docker Compose (Рекомендуемый способ)

Убедитесь, что служба Docker запущена на вашем компьютере.

1. Соберите и запустите контейнеры:
   ```bash
   docker compose up --build
   ```

2. Откройте веб-интерфейс в браузере:
   ```text
   http://localhost:8080
   ```

3. Для прямого доступа к API и документации откройте:
   ```text
   http://localhost:8000/api/docs/
   ```

При первом старте контейнер бэкенда автоматически выполняет миграции и наполняет базу демонстрационными данными.

Для остановки контейнеров выполните команду:
```bash
docker compose down
```

## Локальный запуск для разработки

### 1. Запуск бэкенда (Django)

Требуется Python версии 3.11 или выше.

1. Перейдите в каталог бэкенда:
   ```bash
   cd backend
   ```

2. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   ```

3. Активируйте виртуальное окружение:
   - В Windows (PowerShell):
     ```powershell
     .venv\Scripts\Activate.ps1
     ```
   - В Linux / macOS:
     ```bash
     source .venv/bin/activate
     ```

4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. Примените миграции базы данных:
   ```bash
   python manage.py migrate
   ```

6. Заполните базу демонстрационными данными:
   ```bash
   python manage.py seed_data
   ```

7. Запустите сервер разработки:
   ```bash
   python manage.py runserver 127.0.0.1:8000
   ```

Сервер бэкенда будет доступен по адресу `http://127.0.0.1:8000`.

---

### 2. Запуск фронтенда (Vue 3 + Vite)

Требуется Node.js версии 20 или выше.

1. Откройте новый терминал и перейдите в каталог фронтенда:
   ```bash
   cd frontend
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки Vite:
   ```bash
   npm run dev
   ```

4. Откройте приложение в браузере по адресу `http://localhost:5173`.
Запросы к `/api/` автоматически проксируются на бэкенд `http://127.0.0.1:8000`.

## Запуск тестов

Для запуска набора автоматических тестов бэкенда выполните команду:

```bash
cd backend
python manage.py test catalog --verbosity 2
```

Тестовый набор проверяет:
- Уникальность номеров треков внутри одного альбома.
- Вхождение одной песни в разные альбомы с разными порядковыми номерами.
- Запрет повторного добавления одинаковой песни в один альбом.
- Каскадное удаление связей при сохранении независимых сущностей.
- Работу всех конечных точек REST API, валидацию и фильтрацию.

Для проверки сборки фронтенда выполните:
```bash
cd frontend
npm run build
```

## Основные конечные точки REST API

- `GET /api/v1/albums/` — список альбомов с фильтрацией по году, исполнителю и текстовому поиску.
- `POST /api/v1/albums/` — создание альбома со списком треков.
- `GET /api/v1/albums/{id}/` — детальная информация об альбоме с упорядоченным треклистом.
- `POST /api/v1/albums/{id}/tracks/` — добавление трека в альбом.
- `DELETE /api/v1/albums/{id}/tracks/{track_id}/` — исключение трека из альбома.
- `GET /api/v1/artists/` — список исполнителей с количеством альбомов.
- `GET /api/v1/songs/` — список песен с перечнем всех альбомов и номеров позиций.
- `GET /api/v1/stats/` — сводная статистика каталога.
